Redact-It — E2E Test Page

Three image fixtures used to verify the context-menu + image-capture pipeline.

Fixture 1 — HTTP src (relative path)

A normal <img> loaded from a relative HTTP URL. The background service worker must fetch this URL directly.

Fixture 2 — Blob URL (created via Blob API)

An <img> whose src is a blob: URL created by the page. The content script must capture this using canvas.drawImage() rather than a fetch.

Fixture 3 — Inline data: URI

A 1×1 red pixel encoded as a data: URI. No network request is made; the content script must handle this by reading the src directly or drawing to canvas.
