Then install it — four steps, about 30 seconds

  1. Unzip shotglow.zip somewhere permanent. Chrome loads it from that folder every time it starts.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode, the toggle in the top-right.
  4. Click Load unpacked and pick the shotglow folder.

It isn't on the Chrome Web Store, so this is the same "load unpacked" route developers use daily. To update later, unzip a newer release over the same folder and hit refresh on the extensions page.

Right-click, redact, paste

Shotglow lives in Chrome's context menu. Any image on any page, a screenshot in a Slack thread, a chart in a dashboard, is one click from the editor.

  1. Right-click the image

    Choose Shotglow. The editor opens in its own window with that exact image loaded. Nothing to save, upload, or drag anywhere.

  2. Drag boxes over the sensitive bits

    Adjust the strength for a coarser mosaic. Cmd Z if you overshoot.

  3. Frame it, if you want

    Background, padding, rounded corners, shadow. The preview always matches the file you'll get.

  4. Copy, then paste it straight back

    Cmd C puts the finished PNG on your clipboard. Paste it into Slack, a doc, an email, an issue. No file to hunt for afterwards.

What it does

Mosaic redaction
Four strength levels, lightly scrambled through to unrecoverable. The pixels are destroyed, not covered by a box someone can drag off.
Framing
Margin, image scale, corner roundness, drop shadow.
Backgrounds
Solid colors, eight gradient presets, a custom two-stop gradient, bundled mesh wallpapers. Optional dot, grid, diagonal or crosshatch overlay on top.
Aspect ratios
Auto, 1:1, 4:3, 16:9. The frame expands to fit; your image is never cropped.
Copy or download
Straight to the clipboard, or saved as a PNG.
Runs locally
No account, no upload, no server. There is nowhere for your screenshot to go.
